## SuperL - 语言学习助手

一款基于 Steve Kaufmann 语言学习理念设计的 Android 应用，通过文本与语音的结合，帮助你高效学习外语。

## 🎯 设计理念

本应用基于著名多语言学习者 Steve Kaufmann 在 YouTube 上分享的外语学习方法论：

通过反复听读结合，让语言学习变得自然而高效。

## ✨ 核心功能

### 📁 自由导入学习材料
- 支持导入自己的学习文本
- 灵活管理学习内容

### 🤖 AI 智能阅读
- AI 语音合成技术
- 自然流畅的朗读效果
- 支持多种语言

### 💾 保存与反复练习
- **保存文本和语音**：一键保存学习材料
- **随时回顾**：离线也能反复听、反复看
- **沉浸式学习**：通过重复强化记忆

### 📚 生词本管理
- 学习过程中遇到的生词可即时添加
- 构建个人专属词汇库
- 便于定期复习巩固

## 🎓 学习方法

Steve Kaufmann 的核心学习法则：

1. **多听**：大量接触目标语言的声音
2. **文音对应**：阅读文本的同时听相应的音频
3. **重复是关键**：反复听读同一材料直到完全理解
4. **兴趣驱动**：选择自己感兴趣的学习内容

SuperL 正是为践行这一理念而生。

## 🚀 使用指南

1. **导入文本**：将你想学习的外语文本导入应用
2. **AI 朗读**：点击播放，让 AI 为你朗读文本
3. **保存材料**：保存文本和语音，方便随时复习
4. **添加生词**：学习过程中遇到的生词添加到生词本
5. **反复练习**：多次听读同一材料，直至完全掌握
